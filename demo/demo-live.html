Act 7 · Recording



  
Act 7
Recording: turn the real API into a mock
~3 minSwitch the tenant first

  
While recording, Mockifyr is a reverse proxy with a tape deck: it forwards,
  it copies; the snapshot turns the copies into stubs.

  
Dashboard · tenant + Recordings
    
Tenant → Globex (Stubs is empty: isolation) → Recordings: Target http://localhost:9090 → Start recording

  
./demo/demo.sh record-drive

    
responses come from the real API (INV-2041, currency: EUR) — the mock only forwards and records

    

  
Dashboard · Recordings
    
Snapshot → "Captured stubs · 2" → Import all → the real API copied without writing a single stub by hand

  
./demo/demo.sh drift

    
Optional the "real" API silently changes: currency disappears, settlementBatch appears

    

  
./demo/demo.sh record-verify

    
Optional the drift report: fieldMissing /settlementBatch · fieldUnexpected /currency

    

  
./demo/demo.sh record-stop

    
recording ends → the stubs answer from now on; the real API can leave the stage

    

  
Dashboard · tenant
Tenant → back to Acme Pay

  
If you use verify, always run it BEFORE stop — stop clears the recorded traffic.

Act 9 · Enterprise sign-in (SSO)



  
Act 9
Dashboard sign-in with OIDC
Optional · Separate setup

  
The admin surface plugs into the corporate identity provider: the dashboard
  login becomes SSO (authorization code + PKCE), the token's tenant claim locks the user
  to one tenant, and the audit trail records every change as
  oidc:demo.
  This act swaps long-lived processes, so it runs from a terminal:

  
Terminal · One command
    
./demo/start.sh sso → Keycloak (Docker, realm pre-imported) + the OIDC engine + upstream + runner,
    all together · users: demo/demo123 (acme-pay) and globex/globex123 (globex) ·
    in this mode the whole flow still works — the steps fetch their own tokens (verified 33/33 green) ·
    back to normal: ./demo/stop.sh && ./demo/start.sh

  
Browser · The show
    
Open the dashboard → locked screen + "Sign in with your identity provider" → the Keycloak page →
    demo/demo123 → redirected back, signed in. A token-less curl /__admin/mappings → 401;
    the user can only manage acme-pay (the claim lock). Basic auth keeps working next to it for machine accounts.
